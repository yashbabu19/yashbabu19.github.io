# Yash Babu — Portfolio

Responsive, single-page engineering portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in any modern browser. No build step or package installation is required.

## Deploy to GitHub Pages

1. Push these files to the `main` branch of `yashbabu19/yashbabu19.github.io`.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main`, folder `/(root)`, then save.
5. Visit `https://yashbabu19.github.io/` after the Pages build completes.

## Before sharing

- Verify the mobile layout on real devices and test the links.
- Review professional experience details for confidentiality.
- The interactive terminal uses illustrative static output; it does not execute GatewayLens.
- Animations respect `prefers-reduced-motion`.
